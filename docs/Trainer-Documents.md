## 3. Programme delivery records

The trainer should submit or maintain the following records for each assigned course or cohort.

| Record | Frequency | Submitted / stored | Notes |
|---|---|:---:|---|
| Delivery plan and session schedule | Before delivery begins | ☐ |  |
| Session lesson plans and learning materials | Before each session or module | ☐ |  |
| Attendance register | Every session | ☐ |  |
| Assessment brief, rubric, and learner feedback | Per assessment | ☐ |  |
| Learner progress or intervention notes | As required | ☐ |  |
| Incident, safeguarding, or welfare report | Immediately when required | ☐ |  |
| End-of-course summary and recommendations | At course completion | ☐ |  |
| Trainer reflection and improvement notes | At course completion | ☐ |  |
